## Reviewer notes

This matrix is the ECSS-Q-ST-60/DO-254-shaped view of the same requirements the build enforces via scripts/trace_check.py (no requirement without a test) and scripts/regmap_gen.py (no map drift). The formal rows are machine-checked theorems; the test rows run in the ci/test/formal/arch workflows on every push; the tool rows (tmr-guard, coverage, beam analysis) carry their own negative controls. The gap this pilot closes: a template proves nothing, a filled matrix that regenerates from the gated source proves the evidence chain is real and current.
